# Raman Palla — Personal Portfolio

A responsive, dark-premium personal portfolio built with HTML, CSS and vanilla JavaScript. The Projects section now uses the four authentic website screenshots supplied for TSL Digital, TSL Commerce, TSL Logistics & Transportation, and Shivam Golden Carriers.

## Run locally
Open `index.html` in any modern browser. Keep the `assets` folder beside the HTML file.

## Deploy free (no paid domain required)
### Netlify
1. Create a free account at https://www.netlify.com/.
2. Choose **Add new site → Deploy manually**.
3. Drag and drop the extracted `raman_palla_portfolio` folder.
4. Netlify will provide a free `*.netlify.app` URL.

### GitHub Pages
1. Create a GitHub repository and upload all files, including the `assets` folder.
2. In repository **Settings → Pages**, select deploy from the `main` branch and root folder.
3. GitHub will provide a `username.github.io/repository-name` URL.

## Before publishing
- Confirm the public contact email and phone number are correct.
- The contact form currently uses a `mailto:` link; direct form submissions require a form backend such as Netlify Forms or Formspree.
- Skill bar percentages are illustrative self-assessments; adjust them to accurately reflect proficiency.
