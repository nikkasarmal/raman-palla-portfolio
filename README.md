# Raman Palla — Personal Portfolio (SEO + Freelance Optimized)

Updated static portfolio preserving the original dark-premium design. Built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content, SEO metadata and Person structured data
- `style.css` — original design plus live-project link styling
- `script.js` — navigation, reveal effects and contact form
- `favicon.svg` — browser icon
- `robots.txt` — crawler guidance and sitemap location
- `sitemap.xml` — homepage sitemap

## Publish to the existing GitHub Pages repository
1. Extract this ZIP.
2. Copy all files into the root of your existing repository, replacing the old files when prompted.
3. Keep the existing repository and GitHub Pages settings unchanged.
4. In VS Code terminal run:

```bash
git add .
git commit -m "Optimize portfolio for freelance web and UI UX work"
git push
```

## Verify after deployment
- Homepage: https://nikkasarmal.github.io/raman-palla-portfolio/
- Robots: https://nikkasarmal.github.io/raman-palla-portfolio/robots.txt
